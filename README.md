## 🚀 Démarrage rapide

```bash
# Cloner
git clone https://github.com/<user>/<repo-kaamelott>.git
cd <repo-kaamelott>

# Lancer un serveur simple (au choix)
# 1) Python
python3 -m http.server 5173
# 2) Node (serve)
npx serve .
```

> Ouvre ensuite : `http://localhost:5173` (ou l’URL indiquée par l’outil)
