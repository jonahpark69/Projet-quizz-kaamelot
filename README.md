# 🎯 Quiz Kaamelott – Qui a dit ça ?

Un jeu interactif autour des répliques cultes de la série *Kaamelott* par Alexandre Astier. Devinez quel personnage a prononcé chaque citation !

## 🚀 Fonctionnalités
- Sélection de niveau (facile, moyen, difficile)
- Mode normal ou mode chrono
- Score dynamique et feedback audio
- Interface immersive inspirée de l’univers Kaamelott

## 📦 Technologies utilisées
- HTML5 / CSS3
- JavaScript Vanilla
- Stockage local avec `localStorage`
- Organisation des fichiers selon les bonnes pratiques
